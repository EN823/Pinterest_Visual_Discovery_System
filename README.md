**Pinterest Visual Discovery System**


**Project Description**

The Pinterest Visual Discovery System is a C++ console-based application inspired by Pinterest. It allows users to search for visual content based on different categories and explore related visual discoveries through an interactive menu.


**Features**
- Search for visual content by category
- Browse available visual discoveries
- Interactive menu-based navigation
- Simple and user-friendly console interface
- C++ implementation


**Source Code**

The main source code for this project is:
- pinterest.cpp


**How to Run**
1. Download or clone this repository.
2. Open pinterest.cpp using a C++ compatible IDE such as Visual Studio Code.
3. Compile the program using a C++ compiler.
4. Run the compiled program.
5. Follow the instructions displayed in the console.

**Technologies Used**
- C++
- Visual Studio Code


**Project Purpose**

This project demonstrates the concept of visual discovery inspired by Pinterest through a simple interactive C++ system.
